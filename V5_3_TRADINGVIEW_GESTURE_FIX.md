# V5.3 — TradingView Gesture Fix

Bu sürümde Lightweight Charts'ın native mobil gesture davranışına güvenmek yerine public range API'leri üzerinden deterministik gesture katmanı eklendi.

- Grafik gövdesi: X + Y serbest pan
- Sağ fiyat ekseni: yalnız dikey fiyat ölçeği
- Alt zaman ekseni: yalnız yatay zaman ölçeği
- İki parmak pinch: X + Y birlikte zoom
- PC mouse sürükleme ve wheel desteği
- Native gesture çakışmaları kapatıldı
- VWAP / Üçgen / Düşen Trend / Alternasyon tarama mantıkları değiştirilmedi
