# V5.2 — TradingView Lightweight Charts grafik motoru

Bu sürümde el yapımı Canvas gesture motoru kaldırıldı. Grafikler TradingView'in açık kaynak Lightweight Charts 5.2.1 motoruyla çizilir.

- Grafik gövdesinde yatay + dikey parmak sürükleme native.
- İki parmak pinch zoom native.
- Sağ fiyat eksenini sürükleme native dikey scale.
- Alt zaman eksenini sürükleme native yatay scale.
- Momentum / kinetic scroll açık.
- Ayrı hacim paneli yok.
- Hacim, fiyat mumlarının gövde genişliğine yansıtılır (custom series renderer).
- Mobil görünüm sade: üst grafik başlığı ve kompakt kalite kartı kaldırıldı; ayrıntılar grafiğin altındaki expander'da.
- Tarama / VWAP / Üçgen / Düşen Trend / Alternasyon motorlarına dokunulmadı.

Not: Lightweight Charts JS dosyası resmi jsDelivr CDN üzerinden istemci tarayıcısında yüklenir.
